# Odin Recipes

## About the Project

Odin Recipes is a simple recipe website built using HTML as part of [The Odin Project](https://www.theodinproject.com/).

The website contains a homepage that links to three Indian street food recipes.

## Recipes Included

- **Pani Puri** – A popular Indian street food made with crispy puris, potato filling, and spicy flavored water.
- **Pav Bhaji** – A Mumbai street food consisting of spiced mashed vegetables served with buttered bread rolls.
- **Vada Pav** – A famous Maharashtrian snack made with a spicy potato fritter inside a bread roll.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Select a recipe from the homepage to view its details.
